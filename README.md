# Dead Internet Bot

A browser extension designed to parse website DOM content and leverage the Gemini API to generate context-aware, human-like social media interactions.

## Overview

The "Dead Internet" phenomenon explores the idea of automated content generation in digital ecosystems. This project functions as an intelligent agent that navigates social media environments, analyzes local DOM structures, and provides organic, context-aware responses to digital interactions.

## Key Features

- **DOM Parsing:** Automated extraction of website content and social media context.
- **Gemini API Integration:** Uses advanced LLM processing to generate human-like content that mimics natural discourse.
- **Context-Awareness:** Analyzes the digital environment to ensure generated interactions feel organic rather than templated.
- **Prompt Engineering:** Optimized strategies to maintain consistency, tone, and human-like behavior within social media ecosystems.

## Tech Stack

- **Frontend:** JavaScript, HTML, CSS
- **Integration:** Gemini API
- **Platform:** BrowserExtensions API

## Project Goals

- Explore the boundaries of automated interaction in modern digital ecosystems.
- Refine prompt engineering techniques to improve the quality of AI-generated responses.
- Develop a deeper understanding of DOM manipulation and browser extension architecture.

## How It Works

1. **Context Acquisition:** The extension parses the current social media DOM to gather thread context.
2. **Analysis:** The gathered content is passed to the Gemini API for analysis and response generation.
3. **Execution:** The generated content is seamlessly injected into the DOM, mimicking human-like interaction behavior.

## Current Status

This is an ongoing development project. The core logic for DOM parsing and Gemini API integration is functional, and work continues on refining the naturalness of the interactions and the robustness of the prompt strategies.

## Safety & Ethics

This project is intended for research and educational purposes to better understand how automated agents interact within digital platforms. It is not intended for spamming or violating the terms of service of any specific website.
